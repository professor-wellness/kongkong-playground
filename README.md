# 콩콩 놀이터 (시안)

셀카 카메라로 몸을 움직이며 노는 유아 신체놀이 웹앱입니다. 이름은 임시입니다.

**주소:** https://professor-wellness.github.io/kongkong-playground

## 놀이

| 놀이 | 하는 방법 |
| --- | --- |
| 풍선 팡팡 | 떠오르는 풍선을 손으로 터트리기 |
| 콩콩 스텝 | 내려오는 화살표에 맞춰 발 모으기, 벌리기, 좌우로 딛기 |
| 자세 틀 따라 하기 | 초록 틀과 같은 자세를 5초 안에 잡고 3초 버티기 (10가지 자세) |
| 씽씽 레이싱 | 두 손으로 핸들을 돌려 별 모으기 |
| 쏙쏙 농구 | 좌우로 움직여 조준하고 두 손을 올려 슛, 점프하면 2점 |

모든 놀이는 **혼자 하기**와 **둘이 겨루기**를 고를 수 있습니다. 둘이 겨루기는 가로 화면을 반으로 나눠 두 사람이 같은 문제로 점수를 겨룹니다.

## 쓰는 방법

- 휴대폰 Chrome이나 Safari에서 주소를 열고 카메라를 허용합니다.
- 휴대폰을 세워 두고 2m쯤 떨어져 온몸이 보이게 섭니다.
- TV로 크게 하려면 화면 미러링을 켜고 첫 화면에서 **📺 가로 (TV)** 를 고른 뒤 휴대폰을 옆으로 눕혀 세웁니다.
- 카메라가 없거나 허용하지 않으면 손가락으로 체험할 수 있습니다.

## 개인정보

카메라 영상은 기기 안에서만 처리하며 저장하거나 전송하지 않습니다. 기기에는 모은 별 개수와 화면 방향 설정만 저장됩니다.

## 상태

실제 어린이 대상 정확도와 안전성 시험 전의 시안입니다. 발달 평가나 치료 도구가 아닙니다.

## 파일

- `index.html` 앱 전체 (화면, 놀이, 판정)
- `pose/` 자세 인식 라이브러리 (MediaPipe Pose, Apache-2.0, `pose/NOTICE.md` 참고)
