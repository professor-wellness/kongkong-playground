# 손 인식 라이브러리

이 폴더의 파일은 Google의 MediaPipe Hands (`@mediapipe/hands` 0.4.1675469240)입니다.
Apache License 2.0으로 배포되며, 라이선스 전문은 https://www.apache.org/licenses/LICENSE-2.0 에서 볼 수 있습니다.

`hands_assets.js`는 원본 모델 파일(`hand_landmark_lite.tflite`, `hands_solution_packed_assets.data`, `hands.binarypb`, `hands_solution_simd_wasm_bin.data`)을
웹에서 불러오기 쉽도록 base64로 묶은 것이며, 내용은 바꾸지 않았습니다.
